Meetings do not run long because people are careless. They run long because nobody can see the time. Put a countdown in the room and the meeting starts policing itself.

## Time-box the agenda

Give each agenda item a number: "10 min" for the update, "20" for the decision, "5" for wrap-up. Type the next item's time as you move through the agenda. Starting the next box takes one line of typing.

## Make the clock public

A timer only changes behavior if everyone can see it. Show it large on the room display, take it [full screen](/blog/full-screen-countdown-timer-mac) between slides, or keep it [pinned above the shared screen](/blog/always-on-top-timer-mac). In a standup, the countdown behind the speaker does the moderating for you.

## Count down to the hard stop

Meeting ends at 3pm? Type "3pm" and the timer counts down to the clock time. Everyone can see the runway shrinking, which is remarkably good for reaching decisions.

## Make overtime visible

Turn on [count up after zero](/blog/count-up-after-zero) and the timer keeps counting past the end. The overtime number climbing on screen is the most polite way ever invented to end a meeting.

No meeting-management platform, no integrations, no bot in the calendar. One readable countdown, and suddenly the agenda means something.
